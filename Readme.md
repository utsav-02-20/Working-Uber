# Next.js + TypeScript + Express

Full-stack project using **Next.js, TypeScript, and Express.js**.

## Tech Stack

* Next.js
* TypeScript
* Express.js
* Node.js

## Setup

```bash
npm install
npm run dev
```

## Structure

```text
client/   → Next.js frontend
server/   → Express backend
```

Frontend: `http://localhost:3000` or `http://localhost:${PORT}`
Backend: `http://localhost:5000`
